Для разработки и использования системы обработки сообщений, описанной выше, выполните следующие шаги:

### 1. Установка dependencies:
```bash
pip install -r requirements.txt
```

### 2. Создание файла `.env`:
Войдите в свой аккаунт Telegram и сохраните токен в файле:
```bash
echo "TOKEN=your_bot_token" > .env
```

### 3. Настройка файлов:
- Создайте или измените файл `bot_system.log` для записи логов.
- Убедитесь, что папка с проектом (например, `system`) создана.

### 4. Запустить систему:
```bash
python main_flow.py
```

### Пример Outputs:
Для визуализации функционала система может выдавать такие сообщения:

- **Пример обработки сообщения:**
  ```
  Processing message "Привет!"
  Message processed by model 't0001'
  Response: Привет!😊
  ```

- **Проактивная проверка inactive messages:**
  ```
  Message [id=12345] is inactive. Updating role to AGITATOR.
  ```

### Использование через Telegram-бот:
```bash
python main_flow.py --token=your_bot_token
```

### Дополнительные настройки:
- Управление чёрным списком через `db.set_blacklisted(user_id)` в .env.
- Настройка96 of FULL_SCORING_INTERVAL для управления резервными моделями.

Для более детального понимания работы системы и разработки рекомендуется изучение кодаeach component и их взаимодействия.
