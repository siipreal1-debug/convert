Система бота представляет собой сложную асинхронную систему, разработанную для эффективного обработки сообщений из Telegram с использованием LLM. Она включает несколько ключевых компонентов:

1. **Database**: Управляет базой данных, которая содержит информацию о пользователях, их активности и историях.

2. **RAGManager**: Обеспечивает доступ к RAG-модулю, который объединяет тексты с контекстом из базы данных, храня необходимую информацию для обработки сообщений.

3. **LLMManager**: Управляет логированием и обработкой вызовов LLM, включая хранение токенов и логирование.

4. **LangGraph (app)**: Асинхронный граф обработки сообщений, который включает несколько нод для различных операций: перевода текста, выбора роли, проверки контекста и генерации ответа.

5. **UI**: Класс для управления интерфейсом, который добавляет логирование, управление сессиями и обработку вводных данных.

6. **main()**: Запускающий функционал программы, который инициализирует все объекты и запускает Telegram-бот.

Основные этапы работы бота:
1. Создание базы данных.
2. Создание RAGManager, LLMManager и графа обработки.
3. Запуск Telegram-бота.
4. Обработка сообщений из Telegram: добавление в очередь, прохождение через граф, формирование ответа и отправка.

Для работы системы необходимы следующие условия:
- Python 3.7 или выше.
- библиотеки: asyncio, fastapi, langchain, docarray, numpy, pandas, openai, python-dotenv.
- файл .env для настройки параметров.
- узкоканALайн-соединение для работы с Telegram.

Для запуска программы выполните команду:
```bash
pip install -r requirements.txt
python main_flow.py
```

Система поддерживает работу до 50 LLM и эффективно экономит токены за счет полного скоринга редко.
