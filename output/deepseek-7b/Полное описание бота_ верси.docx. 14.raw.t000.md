Для работы с системой полного Scorинга выполните следующие шаги:

1. **Установка необходимых пакетов**:
   Настраивайте Python и установите библиотеки:
   ```bash
   pip install -r requirements.txt
   ```

2. **Настройка .env файла**:
   Создайте файл `.env` с токенами Telegram-бота и настройками:
   ```env
   BOT_TOKEN=your_bot_token
   ```
   Если используется резервный токен, добавьте его в файл:
   ```env
   BOT_TOKEN_BACKUP=backup_bot_token
   ```

3. **Запуск программы**:
   Запустите основную программу через:
   ```bash
   python main_flow.py
   ```
   Это вызывает `ApplicationBuilder`, который инициализирует Telegram-бота и другие модули.

4. **Проверка работы**:
   После запуска бот должен обрабатывать сообщения из канала Telegram. Убедитесь, что все функции работают корректно:
   - Проверьте обработку чёрных списков с помощью кнопки `set_blacklist`.
   - Убедитесь, что при паузе сообщения сохраняется в базе данных.
   - Наблюдайте за логами для анализа функционирования.

5. **Работа с логами**:
   Логи содержат информацию о выполнении задач и ошибках. Для просмотра логов используйте файл `bot_system.log`.

6. **Проверка настроек**:
   Убедитесь, что все настройки в `.env` корректны, включая токены Telegram-бота и настройки системы Scorинг.

7. **Работа с LLM**:
   Для просмотра доступных моделей и их оценки используйте функцию `get_free_llms()`.

8. **Проверка контекста**:
   Убедитесь, что система корректно сохраняет и возвращает контекст для каждого сообщения.

Если возникнут ошибки, проверьте логи и убедитесь, что все необходимые библиотеки установлены и настроены правильно.
