### Решение по шагам:

1. **Установка зависимости**:
   - Убедитесь, что у вас установлены все необходимые библиотеки. Вы можете установить их с помощью pip:
     ```bash
     pip install -r requirements.txt
     ```

2. **Настройка environment variables**:
   - Создайте файл `.env` и добавьте в него следующие environment variables:
     ```
     BOT_TOKEN=your_bot_token_here
     CHAT_ID=123456789  # или оставьте пустым, если используется group chat
     ```
   - Если вы работаете с группой чатов, убедитесь, что CHAT_ID указан правильно.

3. **Запустите бот**:
   - Введите следующую команду в консоль:
     ```bash
     python main_flow.py
     ```
   - Бот должен начать работать и обрабатывать сообщения.

4. **Проверьте логи**:
   - Для просмотра логов можно использовать файл `bot_system.log`, который будет создаваться в папке с ботом.

5. **Убедитесь, что все функции работы бота понятны**:
   - Если возникают ошибки, проверьте логи и уточните, какие функции не работают или требуют улучшения.
