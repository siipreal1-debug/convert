Вот структура системы, основанная на asyncio для асинхронной обработки сообщений, с использованием LLM для генерации ответов и RAG для контекста:

### Классы:
1. **Database**: Управляет базой данных, включая создание таблиц и хранение данных.
2. **RAG**: РеализуетRetrieval-Augmented Generation для работы с контекстом.
3. **LLMManager**: Обеспечивает доступ к LLM-моделям и их вызовам.
4. **ApplicationBuilder**: Создаёт приложение, добавляя хэндлеры и токены.
5. **UI (UI)**: Реализует интерфейс для обработки сообщений и управления состоянием.

### Главные методы:
1. **init_tables()**: Инициализирует базу данных.
2. **get_translating_message()**: Преобразует текст в другую языковую версию.
3. **upsert()**: Вставляет новый вектор в базу данных.
4. **invoke()**: Запрашивает у LLM и возвращает ответ.
5. **start_polling()**: Запускает асинхронный обработчик сообщений.

### Основной цикл:
1. Создаёт объекты базы данных, RAG, LLM и приложения.
2. Запускается Telegram-бот с хэндлером `telegram_handler`.
3. Обрабатывается основной цикл обработки сообщений из очереди.

### Функция `telegram_handler`:
1. Получает обновление из Telegram.
2. Проверяет чёрный список и паузу.
3. Добавляет в очередь для обработки или сохраняет в RAG.

### Основной цикл обработки:
1. Берёт сообщение из очереди.
2. Проходит через граф обработки `LangGraph`.
3. Отправляется ответ и обновляется база данных.

### Граф обработки (`LangGraph`):
1. **translate_message**: Очищает текст, переводит и сохраняет в истории.
2. **judge_role**: Выбирает роль LLM-модели.
3. **retrieve_rag**: Ищу контекст из предыдущих сообщений.
4. **select_llm**: Выбирает подходящую модель для генерации ответа.
5. **generate_response**: Генерирует и скорит ответ.
6. **proactive_check**: Проверяет неактивность сообщений.

### Управление сессиями:
1. Фиксирует лучшую модель для следующих сообщений.
2. Сбрасывается при глобальном скоринге через `FULL_SCORING_INTERVAL`.

### Логирование и сохранение:
1. Записывает ошибки, логи и историю в базу данных.
2. Сохраняет вызовы LLM и контекст RAG.

### Утилиты:
1. **UI-методы**: Добавляет текст в окошки, обновляет состояние чёрного списка и сессий.
2. **set_clean**, **add_blacklist**, **reset_sessions** — управляют состоянием системы.

### Примеры использования:
1. Установите `requirements.txt` и выполните `python main_flow.py`.
2. Настройте `.env`, чтобы указать путь к Telegram-боту и файлам с настройками.
3. Запустите систему для обработки сообщений без пауз и сохранения контекста.

Система эффективно комбинирует асинхронность, LLM-модели и RAG для создания мощного интеллектуального мессенджера.
