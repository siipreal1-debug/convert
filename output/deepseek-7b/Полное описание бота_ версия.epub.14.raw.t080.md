### П lenient Explanation of the Chat Bot System

Этот chat bot (ботов) на основе Symfony с использованием Python для обработки rqequests и asyncio для асинхронного выполнения задач. Система разработана для эффективной обработки сообщений, использования доступных LLM-моделей (например, GPT-3.5 или OpenAI) и сохранения контекста для генерации релевантных ответов.

#### 1. **Base System**
- **Database**: Управляет базой данных, которая содержит таблицы для хранения данных о пользователях, история, логи, связь между ними и т.д.
- **UI (User Interface)**: Пряжина в виде окна с текстовыми панелями и кнопками для управления ботом.
- **Telegram-бот**: Обеспечивает обработку rqequest из API Telegram и добавление сообщений в очередь для обработки.
- **LMlManager**: Загружает доступные LLM-модели из OpenRouter илиfallback.
- **RAG-Manager**: Использует检索-аumented generations для контекстного понимания сообщений.

#### 2. **Language Graph**
Этот граф (LangGraph) представляет собой асинхронный конвейер обработки rqequest. Он состоит из следующих нœдов:
1. **Translate Message**: Переводит текст пользователя на английский язык.
2. **Determine Role**: Выбирает роль для обработки сообщения (например,9AGITATOR или RESCORE).
3. **Retrieve RAG**: Ищет контекст в базе данных для генерации релевантного ответа.
4. **Select LLM**: Выbирает подходящую модель для генерации ответа.
5. **Proactive Check**: Проверяет, неактивна ли модель и обновляет last_activity.

#### 3. **Functions**
1. **Get Messages**: Получение rqequest из Telegram-бота.
2. **Clean Message**: Удаление эмодиций и символов из текста.
3. **Add to Queue**: Добавление чистого сообщения в очередь для обработки.
4. **Translate Message**: Перевод текста на английский язык.
5. **Determine Role**: Выбор роли (AGITATOR, RESCORE или other role).
6. **Retrieve RAG**: Поиск контекста в базе данных.
7. **Generate Response**: Генерация ответа с использованием подходящих моделей.
8. **Score Responses**: Оценка генерированных ответов.
9. **Log**: Обработка ошибок и логирование.

#### 4. **Features**
- **Asynchronous Processing**: Использование asyncio и aiohttp для обработки rqequest параллельно.
- **Efficient Resource Management**: Экономит токены, используя топ- N модели и полный скоринг редко.
- **Contextual Generation**: Генерирует ответы с использованием контекста из базы данных.
- **Session Management**: Сохраняет сессии для фиксации лучшей модели и обновления last_activity.
- **Logging and Error Handling**: Обработка ошибок, логирование и сохранение данных.

#### 5. **Structure**
1. **Database**: Хранил историю, логи,,last_activity и другие данные.
2. **UI**: Пряжина для взаимодействия с пользователем.
3. **Telegram-бот**: Обеспечивает обработку rqequest из API Telegram.
4. **LMlManager**: Загружает доступные модели.
5. **RAG-Manager**: Использует检索 для контекстного понимания.
6. **LangGraph**: Рекомендует подходящую модель и генерирует ответ.

#### 6. **Dependencies**
- Python (>=3.7)
- aiohttp
- asyncio
- sqlite3
- pandas
- numpy
- python-dotenv

#### 7. **How to Run**
1. установите dependencies:
   ```bash
   pip install -r requirements.txt
   ```
2. настройте файлы `.env`:
   ```bash
   export Telegram_BOT_TOKEN='ваш токен'
   export BOT_NAME='название бота'
   export PATH_TORequirements='путь к требованиям'
   export PATH_TOModels='путь к моделям'
   ```
3. запустите бот:
   ```bash
   python main_flow.py
   ```
