Для работы бота Telegram System, описанный в задании, нужно выполнить несколько ключевых шагов:

1. **Инициализация и установка зависимости**
   - Убедитесь, что у вас установлен Python 3.7+ и asyncio 4+.
   - Настраивайте 환 recipira.env, включив там все необходимые переменные (например, TEISR, BOT_TOKEN, и т.д.).

2. **Установка зависимостей**
   - Введите в консоль Python: `pip install -r requirements.txt`.

3. **Запустите бот**
   - Используйте следующую команду в Python REPL:
     ```python
     import asyncio

     async def main():
         from main_flow import app
         await asyncio.run(main())

     asyncio.run(main())
     ```
   - Убедитесь, что выполнены все 初始化ные действия в .env иmain Flow.

4. **Проверка работы**
   - Бot должен быть готов к обработке сообщений, но при first start может потребоваться время для настройки.
   - Используйте утилиты в репозитории для просмотра логов и управления state.
