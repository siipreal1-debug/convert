Для разработки и функционирования бота Telegram-бота с использованием RAG и LLM необходимо выполнить следующие шаги:

1. **Подготовка toxenv файл**
   Создайте файл toxenv с настройками окружения для проекта:
   ```plaintext
   PYTHONPATH=/path/to/your project
   PYTHONUNBUFFERED=1
   STD out=|,PIPE
   ```
   Замените `/path/to/your project` на корневой путь вашей Project directory.

2. **Установка зависимостей**
   Убедитесь, что установлена необходимая библиотека:
   ```bash
   pip install -r requirements.txt
   ```

3. **Создание конфигурационного файла .env**
   Заполните файлы с конфигурацией:
   - BLACKLIST_USER: Установите userId в blacklist.
     ```
     BLACKLIST_USER=12345
     ```
   - BOT_TOKEN: Введите токен бота.
     ```
     BOT_TOKEN=your_bot_token
     ```
   - CHAT_ID: Установите чат-ids в `CHAT_IDS` и добавьте файлы:
     ```
     CHAT_IDS/12345.txt
     CHAT_IDS/67890.txt
     ```

4. **Создание base database**
   Создайте базу данных `bot.db`:
   ```python
   import sqlite3

   conn = sqlite3.connect('bot.db')
   c = conn.cursor()

   c.execute('''
    CREATE TABLE IF NOT EXISTS messages (
        id INTEGER PRIMARY KEY AUTOINCREMENT,
        user TEXT,
        message TEXT,
        chat_id INTEGER,
        timestamp REAL DEFAULT CURRENT_TIMESTAMP
    )''')
   c.execute('''
    CREATE TABLE IF NOT EXISTS history (
        id INTEGER PRIMARY KEY AUTOINCREMENT,
        user TEXT,
        message TEXT,
        chat_id INTEGER,
        timestamp REAL DEFAULT CURRENT_TIMESTAMP
    )''')
   conn.commit()
   ```

5. **Проверка работы main_flow.py**
   Запустите бот с использованием:
   ```bash
   PYTHONPATH=/path/to/your project python main_flow.py
   ```
   Если возникают ошибки, убедитесь, что все dependencies установлены и файлы .env корректны.
