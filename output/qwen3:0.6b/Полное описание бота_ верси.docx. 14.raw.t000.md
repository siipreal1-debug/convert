The system described is a **multi-step, asynchronous AI processing pipeline** for Telegram messages, with the following key components and functionality:

### **System Overview**
- **Asynchronous Processing**: Uses `asyncio` for parallel processing to avoid blocking the main loop.
- **Database**: Manages models, RAG, and session settings.
- **LangGraph**: A custom processing graph for message analysis.
- **UI**: Provides a user interface for message management and logging.

### **Key Components and Steps**
1. **Initialization**:
   - **Database**: Creates tables for models, RAG, and session settings.
   - **RAG**: Initializes with a Pinecone or Qdrant-based embedding system.
   - **LLM**: Initializes with a fixed model or global top models.

2. **Message Processing**:
   - **Telegram Integration**: Handles messages from Telegram, checks for blacklisted users, and stores messages in the queue.
   - **LangGraph Processing**:
     - **Translate Message**: Cleans text (if clean_messages enabled).
     - **Determine Role**: Uses the LLM to select the best model.
     - **Validate Role**: Checks for role validation (e.g., "RESCORE").
     - **Retrieve RAG**: Queries the RAG system to find the best context.
     - **Select Model**: Chooses the best model from available options.
     - **Generate Responses**: Uses parallel processing to generate and score responses.
     - **Save Results**: Stores the final response and updates session settings.

3. **Proactive Checks**:
   - **Last Activity Check**: If a user is inactive, they receive a "AGITATOR" role.
   - **Session Management**: Resets session settings when a user logs out.

4. **Logging and Session Management**:
   - **Logging**: Records errors and LLM calls.
   - **Session Reset**: Removes fixed model settings when a user logs out.

### **Setup Requirements**
- **Dependencies**: Install via `pip install -r requirements.txt`.
- **Environment**: Set up the `.env` file with necessary configuration (e.g., Telegram token).

### **Usage**
- Run `python main_flow.py` after installing the required packages.
- The system handles up to 50 LLM models with full scoring intervals.

This system ensures efficient, asynchronous processing while maintaining user-friendly UI interactions.
