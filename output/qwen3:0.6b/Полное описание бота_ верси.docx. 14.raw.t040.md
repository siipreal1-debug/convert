Система обработки сообщений от Telegram работает асинхронно, обеспечивая эффективное обработка нескольких сообщений в параллели. Вот ключевые аспекты:

1. **Асинхронная обработка**:
   - Продолжается в потоке (асинхронно) с использованием `asyncio` для параллелизма.
   - Обработка одного сообщения не затягивается, что делает систему масштабируемой.

2. **Экономия ресурсов**:
   - Используется **топ-Model** (N) и **полный скоринг** (every 6 сообщений) для сохранения активных моделей.
   - Сбраскается в UI при завершении сессии.

3. **Демонстрация**:
   - Запуск программы: `pip install -r requirements.txt` + настройка `.env`.
   - Окончание: `python main_flow.py` — запускает систему, которая обрабатывает сообщения и сохраняет результаты.

4. **Граф-процессор**:
   - Ноды: `translate_message`, `judge_role`, `validate_role`, `retrieve_rag`, `proactive_check`.
   - Ребра: `Conditional needs_rejudge` для обратного пути к `judge_role`.

5. **История и логирование**:
   - Сохраняются данные в таблицах базы данных.
   - Логирование: `log_error`, `log_llm_call`, `add_history`.

**Пример**:
```python
# Запуск системы
pip install -r requirements.txt
env TELEGRAM_BOT_TOKEN=...
python main_flow.py
```

Система поддерживает до 50 LLM и поддерживает до 50000 токенов, делая её эффективной для обработки сообщений.
