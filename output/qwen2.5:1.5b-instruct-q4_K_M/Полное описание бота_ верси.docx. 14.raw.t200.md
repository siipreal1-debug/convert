## Вопросы о коде

### Имя файла "main.py"
**Ситуация:** Вы нашли имя вашего Python-файла так и не смогли узнать, как это на английском.

Команда:

```bash
python -i main.py
```

И выведете:
```
In [1]: print __name__
'__main__'
```

### Рекурсия в Java
**Ситуация:** Вы столкнулись с тем, что не знаете как наследовать базовый класс или интерфейс из предком-интерфейса (что обычно является "Java style").

Как разрешить ваше предложение?

Приведённая выше команда вызывает "main.py", где и начинается ваш код. 

**Ответ:** В Java не существует такое слово как "Субкласс" - для наследования необходимо воспользоваться конструкции:

```java
public class YourMainClass implements BaseInterface {
   public void someMethod() {...}
}   
```

### Что возвращают переменные lambda?

**Ситуация:** В одном из своих проектов мне пришлось разработать метод в стиле lambda. Проблема: если не сделать точную копию сортировки, что переменная отдает, может выскочить ошибку при вызове метода.

Как устранить проблему?

Ответ:
Приведенная кодовая функция работает, т.к lambda создаёт ссылку на текущую реализацию коллекции.
Таким образом если создать копию сортировки (второй параметр метода `Collections.unmodifiableList`) или создать собственное хранилище/другой список она всё равно превращает коллекцию в "immutable", то не будет исключений.
