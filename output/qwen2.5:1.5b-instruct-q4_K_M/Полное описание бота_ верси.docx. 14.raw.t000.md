### Пример использования и тестирования системы

#### Запуск программы

   ```bash
   pip install -r requirements.txt
   ```

2. **Настройка переменных окружения (.env)**
   ```python

   # Другие настройки, если нужно
   ```

3. **Запуск программы**:
   ```bash
   python main_flow.py
   ```

#### Пример использования

1. **Создание модели (если не существует)**:
   ```python
   models = fetch_free_llms()
   if not models:
       print("Не удалось получить доступ к моделям.")
   else:
       print(f"Успешно получены модели: {models}")
   ```

2. **Обработка сообщения в Telegram**:
   ```python
   from bot_system import db, ui

   async def telegram_handler(update):
       user = update.message.from_user.username
       message = update.message.text
       chat_id = update.message.chat.id

       if user in blacklist:
           return

       await db.add_incoming(user, message)
       await db.add_to_queue(user, message, chat_id)

       state = await db.get_queue_item()
       if not state:
           return

       app.ainvoke(state)
   ```

3. **Обработка графа LangGraph**:
   ```python
   from bot_system import app, rag, llm

   async def translate_message(app_state):
       user, message, chat_id = app_state
       translated_message = await llm.translate_message(message)

       history_entry = {
           'user': user,
           'message': message,
           'translated': translated_message,
           'chat_id': chat_id
       }
       await rag.upsert(translated_message, user, metadata=history_entry)
       await db.add_history(history_entry)
   ```

4. **Обработка роли и проверки**:
   ```python
   async def judge_role(app_state):
       user, message = app_state
       role = await llm.determine_role(message)

       if role == "RESCORE":
           await llm.get_valid_role_score(role, message)
       else:
           await rag.query()
   ```

5. **Обработка скоринга и фиксации сессии**:
   ```python
   async def select_llm(app_state):
       user = app_state['user']
       models = await db.get_setting("active_llms", [])
       if not models:
           return

       global_count = await db.get_setting("global_message_count", 0)
       count = (global_count + 1) % FULL_SCORING_INTERVAL
       if count == 0:
           models = active_llms
       else:
           models += [models[-1]]
       best_model = await llm.select_best(model=models, role=role)

       await db.set_setting("fixed_llm_{user}", best_model)
   ```

6. **Обработка логов и сохранения**:
   ```python
   async def log_and_save(app_state):
       user, message = app_state
       await rag.upsert(message, user, metadata={"original_text": message})
       await db.set_model_score(user, best_model)

       if not await db.is_active(best_model):
           await db.set_setting(f"fixed_llm_{user}", best_model)
   ```

### Вывод

Система `bot_system` обеспечивает асинхронное обновление модели, экономию токенов, поддержку до 50 LLM и полный скоринг раз в FULL_SCORING_INTERVAL сообщений. Она также позволяет создавать сессии для фиксации лучшей модели и автоматически меняет роль при неактивности.
