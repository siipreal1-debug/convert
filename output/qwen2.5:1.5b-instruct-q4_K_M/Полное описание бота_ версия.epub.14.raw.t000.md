Система "bot_system" представляет собой конвейер обработки сообщений и управления состоянием бота через граф LangGraph (LangChain Graph). Вот подробное описание работы системы:

### 1. Запуск программы

- **Основной цикл**:
  - Создается база данных `db` с таблицами для истории, логов, очереди и настроек.
  - Создается объект `rag` для обработки релевантного контекста из RAG (Relevance-aware Graph).
  - Создается объект `llm` для взаимодействия с LLM (Language Model Interface).
  - Загружены модели из API или фаллов.
  - Граф `app` создан и добавлен в ноды, ребра и условные переходы.

- **Telegram-бот**:
  - Инициализируется через `ApplicationBuilder`.
  - Хэндлер для обработки сообщений определен в функции `telegram_handler`.

### 2. Чтение сообщений из Telegram

- **функция telegram_handler**:
  - Получает update (сообщение).
  - Извлекает пользователя, текст и чат.
  - Если пользователь в черном списке — игнорирует.
  - Добавляет сообщение в UI.
  - Если пауза — сохраняет сообщение в RAG с метаданными.
  - В противном случае:
    - Очищает текст (если чистим).
    - Добавляет в очередь.

### 3. Обработка сообщений в графе LangGraph

- **функция app.ainvoke**:
  - **translate_message**: переводит текст и сохраняет его в истории.
  - **judge_role**: выбирает роль пользователя.
  - **validate_role**: проверяет роль на соответствие порогу.
  - **needs_rejudge**: если "RESCORE" — вернется к роли "ROLE".
  - **retrieve_rag**: получает контекст из RAG.
  - **select_llm**: выбирает лучшую модель для пользователя (сессионное сохранение).
  - **proactive_check**: проверяет неактивность и меняет роль на "AGITATOR" при необходимости.
  - **generate_response**: генерирует ответы, скорит их, выбирает лучший вариант и фиксирует модель.

### 4. Проактивные действия

- **reset_sessions**: сбрасывает лучшую модель для сессии (сессионное сохранение).
- **full scoring interval**: выполняется полный скоринг раз в `FULL_SCORING_INTERVAL` сообщений (глобально, не по пользователю).

### 5. Логирование и сохранение

- **log_error**:
  - Запись ошибок в логи.
- **db.log_llm_call**:
  - Сохранение LLM вызовов для отслеживания.
- **db.set_model_score**:
  - Вычисление среднего балла после каждого скоринга.

### 6. UI-методы

- **set_clean**: изменяет состояние чистки текста.
- **add_blacklist**: добавляет пользователя в черный список.
- **set_operator**: меняет оператор (например, "admin").
- **toggle_pause**: переключает режим паузы.
- **reset_sessions**: сбрасывает лучшую модель для сессии.

### 7. Сессии и экономия

- **fixed_llm_{user}**:
  - Фиксирует лучшую модель на сессию (сессионное сохранение).
- **global_message_count**:
  - Полный скоринг раз в `FULL_SCORING_INTERVAL` сообщений (глобально, не по пользователю).

### 8. Логирование и сохранение

- **log_error(e, context)**: запись ошибок.
- **db.set_model_score(...)**: вычисление среднего балла после каждого скоринга.

### 9. Примеры использования:

1. **Запуск программы**:
   ```python
   if __name__ == "__main__":
       db = Database()
       ui = UI(db)
       thread = threading.Thread(target=ui.run).start()
       asyncio.run(main())
   ```

2. **Обработка сообщений**:
   ```python
   async def telegram_handler(update):
       user, message, chat_id = update.message.from_user.username, update.message.text, update.message.chat.id
       if db.is_blacklisted(user):
           return

       ui.add_incoming(user, message)
       await rag.upsert(message, user, {metadata={"original_text": message}})
       await db.add_to_queue(user, message, chat_id)

       state = {"user": user, "message": message, "chat_id": chat_id}
       result = app.ainvoke(state)
       response = result['response']
       await application.bot.send_message(chat_id=chat_id, text=response)
   ```

3. **Обработка в графе**:
   ```python
   async def translate_message(state):
       user, message, chat_id = state["user"], state["message"]
       translated_message = translator.translate_to_english(message)
       await db.add_history(user=user, message=translated_message, chat_id=chat_id)
       await rag.upsert(translated_message, user=user, metadata={"original_text": message})
       await db.set_last_activity(chat_id)

   async def judge_role(state):
       role = llm.determine_role(translated_message, default_model="default")
       return {"role": role}

   # И т.д.
   ```
