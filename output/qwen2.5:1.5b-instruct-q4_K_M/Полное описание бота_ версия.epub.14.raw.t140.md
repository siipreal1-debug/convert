Бот является асинхронным приложением на основе asyncio, что обеспечивает высокую производительность и низкое использование токенов благодаря частичному использованию LLM. Вот подробный разбор того, как он работает.

### Шаги Построения Бота

#### 1. Структура Входных Данных
При запуске программного обеспечения:
- **Основная Система**: 
  - Объект базы данных (`db`), который асинхронно initializes в основное меню.
  
  ```python
  db = Database()
  ui = UI(db)
```

- **Центральный Компонент** (загруженный из библиотек `aiogram`, `sqlite3`, `requests`):
  - Запуск приложения с использованием функции `ApplicationBuilder`.
  - Экземпляр API для обработки запросов и управления состоянием.

#### 2. Цикл Асинхронного Появления (main())
```python
if __name__ == '__main__':
    models = fetch_free_llms()
    db = Database()
    rag_manager = RAGManager(pinecone_index) 
    lmm_manager = LLMManager(db)
    
    bot = ApplicationBuilder(token=TELEGRAM_BOT_TOKEN).build()
    bot.add_handler(
        telegram.ext.MessageHandler(filters.command("start"), lambda _, obj: None))  # Простое поведение по умолчанию для бота
```

#### 3. Временное Создание Исполнительных Объектов:
- **Основной** базы данных:
```python
db.init_tables()
```
- **Базовые Функции** 
    - Режим запуска Telegram-бота: `await bot.initialize()`
    - Попытка обновления последнего времени вакуума (когда токен не будет доступен для использования):
        ```python
        async def proactive_check():
            global last_activity
            await asyncio.sleep(1)
            time_now = int(time.time())
            if last_activity is None or time_now - last_activity > 86400:
                db.set_setting("last_activity", str(time_now))
        
            await db.update_global_count()
            
        bot.add_handler(callback=proactive_check, group="daily_tasks")
```

#### 4. Обработка Сообщений и Отправка В ответ
При приходит сообщение на телеграм:
- Экземпляр бота запускает асинхронный цикл `asyncio.run(main())` для обработки состояния:
    ```python 
    while running and bot.polling():
        item = await db.get_queue_item()
        state = translate_message(item)
        
        response = lmm_manager.app.ainvoke(state)

        if 'text' in response:
            asyncio.run(bot.send_message(chat_id=item.chat_id, text=response["response"]))
```

#### 5. Оптимизация Значениями Сессией и Проактивным Фактором
- **Сессии**:
    - Если текущее время `user` из сессий (пересылки) больше или равно `last_activity + random(min, max) * 60` - обновление состояния.
        
```python
@lmm_manager.on_message("RESCORE")
...
reset_sessions()
```

- **Проактивные Действия**:
    - Глобальное проверка на ненадежность:
        ```python
        async def proactive_check():
            ...
            await db.set_setting(f"last_activity_{user}", str(int(time.time()) + random.random() * 60)) 
            await db.update_global_count()
            
        bot.add_handler(callback=proactive_check, group="daily_tasks")
```
#### 6. Использование Личных Услуг:
- **Проход через ЛЛМ** в определенных нодах графа (среди "judge", "validate", etc.). Делается асинхронно с помощью функций `llm.determine_role()` и т.д.

### Заключение
Этот бот является асинхронным приложением, работающим на основе асинхронной обработки задач (последовательности), что обеспечивает низкое потребление токенов в сортировках и поиском контекста. Проактивные механизмы заставляют его адаптироваться к неустойчивым условиям (надежность улучшается через случайное обновление состояния), что помогает существенно повысить точность обработки в таких условиях.
