## Система для обработки и анализа сообщений

### Описание системы:
В данной системе реализовано решение, которое позволяет автоматизировать обработку сообщений от пользователей и анализ их содержания, используя асинхронный подход с использованием библиотек asyncio и asyncpg для выполнения запросов к базе данных. Система также обеспечивает экономию токенов (помещение в БД) и поддержание логов обработки сообщений.

2. **Класс `UILogger`**: Класс, который позволяет обрабатывать логирование сообщений и ошибок.

```python
class UILogger:
    def __init__(self):
        self.log_file = 'bot_system.log'

    async def log_error(self, e, context=None):
        with open(self.log_file, 'a') as f:
            f.write(f'Error: {e}\n')
```

### Внешний код программы:

```python

from .database import Database

async def main():
    db = await Database('bot.db').init_tables()
    
    ui = UI(db)
    application = ApplicationBuilder().token(TELEGRAM_BOT_TOKEN).build()

    bot = application.bot
    bot.add_handler(application.telegram_handler)
```

