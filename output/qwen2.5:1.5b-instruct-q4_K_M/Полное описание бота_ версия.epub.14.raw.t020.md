Система "bot_system" представляет собой асинхронную программу для обработки сообщений через Telegram и управление состоянием пользователей. Вот более подробный анализ её работы:

### 1. Запуск программы

- **Основной цикл**: `asyncio.run(main())`
- **Инициализация базы данных (`db`)**: 
  ```python
  db = Database()
  await db.init_tables()
  ```
- **Инициализация графа (`app`) и робота (`application`)**:
  ```python
  models = fetch_free_llms()  # запрос к OpenRouter API или fallback
  rag = RAGManager(db)  # создание объекта робота для обработки сообщений
  llm = LLMManager(db)
  app = create_workflow(db, rag, llm)
  application = ApplicationBuilder().token(TELEGRAM_BOT_TOKEN).build()
  await application.initialize()  # добавление хэндлера для Telegram-бота и запуск бота
  ```
- **Запуск Telegram-бота**:
  ```python
  telegram_handler = lambda update: ui.add_incoming(update.user.id, update.message.text)
  await application.bot.start_polling()
  ```

### 2. Чтение сообщений из Telegram

- **Telegram-хэндлер (`telegram_handler`)**:
  ```python
  async def telegram_handler(update):
      user = update.message.from_user.username
      message = update.message.text
      chat_id = update.message.chat.id
      if db.is_blacklisted(user):
          return

      ui.add_incoming(user, message)
      await rag.upsert(message, user, metadata={original_text: message, author: user, is_bot: 0})
      if paused:
          await rag.upsert(message, user, {metadata=...})  # сохранение без обработки
      else:
          item = await db.get_queue_item()
          state = State(user=user, message=message, chat_id=chat_id)
          result = app.ainvoke(state)
          response = result['response']
          await application.bot.send_message(chat_id=chat_id, text=response)
  ```

### 3. Обработка сообщений в графе (`app.ainvoke`)

- **Обработка текста**:
  ```python
  async def translate_message(state):
      translated_message = translator.translate_to_english(state.message)
      await db.add_history(..., state.user, ...)
      await rag.upsert(translated_message, state.user, metadata={...})
      update_last_activity()
  ```
- **Проверка роли**:
  ```python
  async def judge_role(state):
      role = llm.determine_role(translated_message, default_model)
      if not validate_role(role, translated_message):
          role = "RESCORE"
      await rag.query(..., state.user)  # ищет контекст
      best_model = select_llm(state.user)
      await db.set_setting(f"fixed_llm_{state.user}", best_model)
      await db.add_history(..., state.user, ...)
      await rag.upsert(translated_message, state.user, metadata={...})
  ```
- **Проверка необходимости повторной проверки роли**:
  ```python
  async def needs_rejudge(state):
      if role == "RESCORE":
          return True
      else:
          retrieve_rag()
  ```
- **Выбор модели для скоринга**:
  ```python
  async def select_llm(state, models=models, count=0):
      global_count = await db.get_setting("global_message_count", 0)
      if count % FULL_SCORING_INTERVAL == 0:
          return all_active_llms
      else:
          top_n = round(len(all_active_llms) / N + X)
          outsider = get_outside_models(top_n, models)
          return select_top_models(outsider, models)
  ```
- **Проактивные действия**:
  ```python
  async def proactive_check(state):
      if not active and time.time() > last_activity + random.randint(INACTIVITY_MIN, INACTIVITY_MAX * 60):
          role = "AGITATOR"
          await application.bot.send_message(chat_id=state.chat_id, text="Provoke!")
  ```
- **Сессии и экономия**:
  ```python
  async def reset_sessions(state):
      db.set_setting(f"fixed_llm_{state.user}", models[0])
      db.set_model_score(state.user, best_model)
  ```

### 4. Логирование и сохранение

- **Логирование ошибок**:

  ```python
  async def log_error(e, context):

  ```
- **LLM-вызовы**:
  ```python
  await db.log_llm_call(...)
  ```

- **История сообщений**:

  ```python
  await db.add_history(..., state.user, ...)
  ```
- **Скоринги модели**:

### 5. UI-методы

- **UI-хэндлеры**:
  ```python
  def set_clean(self):
      self.clean_messages = True
  def add_blacklist(self, user):
      db.set_setting("blacklist_{user}", True)
  def set_operator(self, value):
      db.set_setting("operator", value)
  def toggle_pause(self):
      self.paused = not self.paused
  def reset_sessions(self):
      db.reset_sessions()
  ```

### Заключение

Система "bot_system" обеспечивает асинхронное обновление состояния пользователей, экономит токены с использованием полного скоринга и выбором N лучших моделей, поддерживает до 50 LLM. Она также управляет проактивными действиями и сохраняет историю сообщений для анализа.
