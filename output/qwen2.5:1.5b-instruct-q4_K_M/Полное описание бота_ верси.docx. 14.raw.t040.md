Система обработки сообщений и управления состоянием пользователей в Telegram используется для автоматической транскрибации текстовых сообщений пользователями, определения их ролей и принятия соответствующих действий. Вот более подробный описательный план системы:

### 1. **Основные Технологии и Основы**
- **Токен Telegram**: Захват токена для доступа к API Telegram.
- **База Данных (DB)**: Используется SQLite для хранения истории сообщений, логов и других данных.
- **Параллельное Вычисление (Parallel Computing)**: Используется для быстрого обработки запросов к базе данных с использованием параллелейных вычислений.
- **Асинхронная Обработка (Asynchronous Processing)**: Используется для асинхронной обработки сообщений и управления состоянием пользователей, что позволяет эффективно использовать токены.

### 2. **Основные Функции и Структуры**

**1.1. Запуск программы (main.py)**
- Создание базы данных для хранения истории, логов и других данных.
- Инициализация модели и настроек.
- Создание графа LangGraph для обработки сообщений.
- Запуск Telegram-бота.

**1.2. Чтение Сообщений из Telegram (telegram_handler)**
- Получение и обработка сообщений с использованием токена Telegram API.
- Извлечение данных пользователя, сообщения и чата.
- Проверка наличия пользователей в черном списке.
- Запись в очередь для дальнейшей обработки.

**1.3. Обработка сообщений в графе LangGraph (ainvoke)**
- Очистка и перевод текста сообщения.
- Выбор роли пользователя с использованием множественных судей.
- Ищет контекст из репликатов и сохраняет его в базу данных.
- Выбор лучшей модели по скорингу и фиксирует модель на сессию.
- Скорит модели для определения лучшего варианта ответа.
- Сохранение результатов в истории и базу данных.

**1.4. Проактивные действия (proactive_check)**
- Обновление последнего времени активности пользователя при новых сообщениях.
- Переключение роли на "AGITATOR" для провокационных сообщений, если время прошло за пределами заданного интервала.

**1.5. Сессии и экономия (reset_sessions)**
- Фиксация лучшей модели на сессию в зависимости от типа пользователя.
- Полный скоринг раз в определенное количество сообщений для каждого пользователя.

**1.6. Логирование и сохранение данных**
- Сохранение ошибок и логов в файлы.
- Сохранение истории, логов и других данных в базу данных.

async def telegram_handler(update: Update) -> None:
    user = update.message.from_user.username
