Инструкция о создании и работы асинхронной системы чат-бота на Python, использующей LLM (Large Language Models) для генерации ответов на сообщения из Telegram, представлена в подробном пошаговом разбивке:

1. **Настройка окружения**:
   - Убедитесь, что у вас установлены необходимые пакеты Python и их зависимости. Вы можете сделать это, выполнив команду `pip install -r requirements.txt`.
   - Создайте файл `.env` для настройки переменных окружения, таких как `TELEGRAM_BOT_TOKEN`, `ROLE_SCORE_THRESHOLD`, `FULL_SCORING_INTERVAL` и любых других необходимых параметров.

2. **Запуск системы**:
   - Запустите систему, выполнив команду `python main_flow.py`. Это запустит основной цикл обработки сообщений Telegram и управление работой бота.

3. **Асинхронная обработка сообщений**:
   - Когда пользователь отправляет сообщение, UI-метод `add_incoming` добавляет его в очередь с помощью `db.add_to_queue`. Если пауза или чистка активны, обработка будет пропущена.
   - Основной цикл (`while running`) асинхронно проверяет очередь и запускает граф-асинхронный процесс для каждого сообщения в очереди. Это включает:
     - Перевод сообщения на английский язык.
     - Выбор роли с помощью LLM (`judge_role`).
     - Проверка роли с помощью множественных судьев, если необходимо ("RESCORE").
     - Поиск контекста в RAG для лучшего ответа.
     - Генерация и скореение ответов LLM.
     - Выбор лучшей модели на основе среднего скорринга.
   - Обработанное сообщение отправляется пользователю, а очередь удаляется. Если произошла ошибка, она будет логирована и не удалена из очереди для повторного попытка.

4. **Проактивные действия**:
   - Проактивный метод `proactive_check` проверяет наличие простоя (неактивность) пользователя, и если обнаружено, роль изменяется на "AGITATOR", чтобы спровоцировать сообщение.

5. **Сессии и экономия**:
   - Система фиксирует лучшую модель для каждого пользователя (`fixed_llm_{user}`), что позволяет сэкономить токены LLM, используя только лучшие модели в основном скоринге.
   - Метод `reset_sessions` удаляет фиксированные модели для начала новой сессии.

6. **UI-методы**:
   - UI-методы (`set_clean`, `add_blacklist`, `toggle_pause`, `ui.remove_*`) управляют пользовательским интерфейсом, позволяя настраивать параметры работы системы и отслеживать сообщения в окошках.

Помните, что логирование (в файле `bot_system.log`) поможет вам решать любые возникающие проблемы или вопросы во время запуска. Убедитесь, что все необходимые папки и файлы настроены правильно в `.env` и `requirements.txt`.
