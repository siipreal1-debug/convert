Конечно! Вот обзор основных шагов и функций в вашем приложении:

1. **Запуск программы**:
   - Создается объект базы данных `db` для UI.
   - Создается UI-окно с текстами и кнопками.
   - Запускается асинхронный цикл: `asyncio.run(main())`.

2. **Инициализация в main()**:
   - Инициализирует базу данных.
   - Инициализирует графику обработки сообщений (`app.ainvoke`).
   - Запускается Telegram-бот.

3. **Обработка в графе LangGraph (app.ainvoke, асинхронно)**:
   - Метод `translate_message` обрабатывает текстовое сообщение.
     - Очищает сообщение (если `clean_messages`).
     - Обрабатывает сообщение и сохраняет его в истории (`db.add_history(...)`) и графику (`rag.query(...)`, `rag.upsert(...)`, `db.set_model_score(...)`, `db.set_model_score(...)`).
   - Метод `judge_role` выбирает роль для сообщения.
     - Выбирает модель с лучшей оценкой (проверяет "RESCORE").
   - Метод `validate_role` проверяет роль и выбирает фиксируемую модель на сессию (`fixed_llm_{user}`).
   - Метод `retrieve_rag` использует библиотеку RAG для поиска контекста сообщения.
   - Метод `select_ r a g` выбирает лучшую модель на сессию и сохраняет её в истории и графику.
   - Метод `proactive_check` проверяет активность модели и выбирает модель, которая лучше всего работает для текущего пользователя.
   - Метод `generate_response` генерирует ответы и сохраняет их в истории и графику.

4. **Проактивные действия**:
   - Функция `log_and_save` записывает логи и сохраняет результаты обработки сообщений.
   - Функция `select_llm` выбирает лучшую модель на сессию и сохраняет её в истории и графику.

5. **Сессии и экономия**:
   - Сбрасывается активность модели на сессию, если она неактивна (`reset_sessions`).
   - Метод `add_log/incoming/response` добавляет тексты в окна-окно.

6. **UI-методы (в классе UI)**:
   - Метод `set_clean` устанавливает чистоту истории.
   - Метод `add_blacklist` удаляет сообщения из黑名单.
   - Метод `set_operator` меняет роль модели на "AGITATOR".
   - Метод `toggle_pause` переключает паузу.

Таким образом, система асинхронная и экономит токены, поддерживает до 50 LLM. Для запуска: pip install -r requirements.txt, запустите `python main_flow.py`. Если есть вопросы, не стесняйтесь задавать.
