Конечно! Вот обзор основных этапов и функций программы:

1. **Запуск программы**:
   - Инициализация базы данных.
   - Создание UI-окна с текстами и кнопками.

2. **Инициализация в main()**:
   - База данных.
   - Регулярные графики (translate_message, judge_role, validate_role, retrieve_rag, select_rag).
   - Обработка пользовательских сообщений.
   - Сохранение состояния в DB и графика.

3. **Обработка в графе LangGraph**:
   - Метод translate_message и проверка модели.
   - Метод judge_role и выбор роли.
   - Регулярные задачи (validate_role, retrieve_rag).
   - Обработка предложенных сообщений и сессии обработки логики.

4. **Проактивные действия**:
   - Глобальная last_activity.
   - Локальные функции для управления модели (set_clean, add_blacklist, set_operator, toggle_pause).
   - Функция set_rag и сохранение результатов.

5. **UI-методы**:
   - Set_clean: устанавливает clean_messages.
   - Add_blacklist: удаляет чат-бота из чата.
   - Set_operator: изменяет режим обработки сообщений.
   - Toggle_pause: переключение paused.
   - Reset_sessions: очищение модели и истории.

Система асинхронна позволяет снизить токены, увеличивая скоринг (получается 50 LLM). Для запуска: pip install -r requirements.txt, настрой .env, запустите python main_flow.py. Если у вас возникли вопросы, постарайтесь связаться с разработчиками.
