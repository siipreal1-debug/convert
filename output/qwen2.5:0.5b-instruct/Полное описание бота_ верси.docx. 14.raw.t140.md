2. Изменим основное событие открытия страницы, чтобы приложение завершало ожидания перед обработкой.

        app = ApplicationBuilder().token(TELEGRAM_BOT_TOKEN).build()

### Замена события открытия окна:
```python
@app.on_startup
async def main():
    async def _():
        # Важно убедиться, что объект Database установлен правильно и присвоен
        await asyncio.gather(app.app.start(), app.run())
```
