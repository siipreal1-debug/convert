# Стандартный класс решения дисбалансированного битеранта с использованием DFS и сжатой蒙сфоуры

## Основной структура системы

Данный класс решения описывает структуру и функциональность гибридного модели для анонимного распределения трафика в битеранте. Важно предварить все учитывания к ресурсам гибридных моделей, которые включают在网络 локально и в глобальном.

### Полезные данные

Для каждой связи будет храниться информация:
- `time`: timestamp
- `source`, `destination`: addresses
- `protocol`: type of link (network or data)
- `address`: absolute path
- `is_local`: boolean indicating if the connection is local

### Структура данных

Данные будут храняться в базе данных `bot.db` как follows:

```
table: db_model
columns:
    source, destination, protocol, address, is_local,
    initial_moderator, model_name, log_id,
    max_connections, global_connection, local_connection
```

### Функциональность

#### Инициализация:

```
async def __init__(self):
    await self.init_db()
    await self.load_initial_models()
    
    self.current_model = None
    self.current_log = []
    
    # Global connection model is created once the global connection has at least one log.
    # This ensures that network layer can handle more than one connection without issues.
    await self.create_global_connection()
```

#### Добавление в базу данных:

Для добавления новой модели в базу данных использовать функцию:
```
await self.add_model(new_model_name, initial_moderator)
```

### Добавление в базу данных

Дополнительные детали можно выделить следующим образом:

1. **Локальная линка**
   Включает только текущую мониторинговую информацию:
   ```
   model: db_model, source: str, destination: str, protocol: type, 
           is_local: True
   ```

2. **Глобальный линка**
   Учитывает все的历史 данные.

### Основные функции сжатаого蒙сфоуры

#### 1. **Сift and merging of multiple models**
   Uses DFS для детерминированных у streak counting:
   - Добавляется каждая новая модель в гибридную модель.
   - Способically сжатый мониторинг.
   - Генерирует комбинированные отчёты.

#### 2. **Obtaining initial models and their parameters**
   - Инициализация наasync для последовательного обработки локальной линки.
   - Проверка корректности по мониторингам.

---

### Дополнительные детали

- Сжатые мониторингы ведутся через локальное и глобальное схемы, проверяя корректность при каждом фиксировании.
- Проверка на повторяющиеся модели по time.
- Используется сжатае с определенным intervalом между мониторингами (full scalability interval).
