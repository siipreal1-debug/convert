#### 1. **Модели (Models)**:
   - Список моделей, на которых будут work visualization and processing.

   ```python
   class Model:
       def __init__(self, name):
           self.name = name
           self.x = None  # 输入
           self.y = None  # Выход

       @property
       def x(self):
           return self._x
       
       @property
       def y(self):
           return self._y

       def get_x(self, x=None):
           if self._x is not None:
               self._x = x
           return self._x

       def get_y(self, y=None):
           if self._y is not None:
               self._y = y
           return self._y
   ```
