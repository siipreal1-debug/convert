4. Создайте класс `LLMManager` для загрузки и установки базы данных LLM-сервиса:
```python
class LLMManager:
    def __init__(self, db):
        self.db = db

    def fetch_free_llms(self, models):
        llm_models = {}
        for i, model in enumerate(models, 1):
            # Ищет модели в OpenAI API и сохраняет их ID
            llm_model_id = openai_llm.fetch_llm_id(model)
            if llm_model_id:
                llm_models[i] = (model, llm_model_id)
        return llm_models
```
