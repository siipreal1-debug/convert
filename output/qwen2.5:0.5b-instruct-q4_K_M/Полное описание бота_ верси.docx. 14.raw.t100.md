Этот код создает систему отслеживания сообщений на Telegram и обработки их через язык ретулизации (LLM). Оно использует библиотеку RAG для хранения эмбеддингов и моделируют ее в базе данных. Код также учитывает активность, чтобы предсказывать дальнейшие действия и обеспечивать эффективную работу системы.

Суть системы:
1. Принимает данные о пользователях (username, сообщение) при входе или перезагружении.
2. Проверяет наличие сообщений в очереди.
3. Обрабатывает команды: "translate_message" и "judge_role".
4. Меняет роль сообщника и удаляет его из истории.
5. Генерирует ответ по инструкции, сохраняется на основе истории.

Особое значение имеют:
- Библиотека RAG для хранения эмбеддингов с вероятностью от 1 до 50% (каждая модель имеет свои вероятности).
- Асинхронное выполнение цикла, что позволяет обрабатывать сообщения в промежутке времени.

Что делать с кодом?
Конечно! Вот как можно использовать этот код:

1. Установить необходимые библиотеки:
```bash
pip install -r requirements.txt
```

2. Запустить программу:
```bash
python main_flow.py
```

3. Добавьте сообщения с телеграм ботом, например:
- /hello: Сообщение с обеих сторон.
- Приветствую тебя, [username]!
- Бот запущен

4. Вы можете добавить дополнительные команды для управления системой:

- "translate_message" (или "translation"): перевод сообщения на языки других ботов.
- "judge_role": оценивает роль пользователя и его сообщений.

Помните, что эффективность системы зависит от технического аспектов, таких как транспорт связи, мощность серверов, идет поступление данных из Телеграм.
